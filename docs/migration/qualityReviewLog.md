# Vue3 이식 코드 평가 로그

이 문서는 Vue3 이식 과정에서 수행한 코드 리뷰/평가를 누적 기록한다.  
앞으로 동일 형식으로 항목을 계속 추가한다.

## 기록 규칙

- 대상 파일/페이지를 명시한다.
- 이슈는 심각도 순서(높음 → 중간 → 낮음)로 정리한다.
- 각 이슈마다 위치, 문제, 영향, 권장 조치를 적는다.

---

## 2026-03-09 - Login.vue 1차 평가

- 대상: `src/views/auth/Login.vue`
- 목적: UI 이식 후 코드 품질/리스크 점검

### 높음

1. 소셜 로그인 `message` 리스너 누적 + 출처 검증 없음
- 위치: `openPopup()` 내부 `window.addEventListener("message", ...)`
- 문제:
  - 소셜 로그인 버튼 클릭 시 리스너가 누적 등록됨
  - `event.origin` 검증이 없음
- 영향:
  - 중복 처리(성공/실패 로직 다중 실행) 가능
  - 외부 메시지 처리 위험으로 인한 보안 리스크
- 권장 조치:
  - 단일 리스너 등록 또는 `once` 처리
  - 허용 origin 검증 후 처리
  - 처리 완료 시 리스너 해제

### 중간

1. 팝업 차단 시 런타임 에러 가능
- 위치: `const popup = window.open(...)` 이후 `popup.close()`
- 문제:
  - 브라우저 팝업 차단 시 `popup`이 `null`일 수 있음
- 영향:
  - 소셜 로그인 실패 처리 중 JS 에러 발생 가능
- 권장 조치:
  - `if (popup)` 체크 후 `close()` 호출

2. 에러 타이틀 문구 불일치
- 위치: `const errorTitle = 'Together 생성 에러'`
- 문제:
  - 로그인 페이지 맥락과 맞지 않는 타이틀
- 영향:
  - 사용자 신뢰/일관성 저하
- 권장 조치:
  - 로그인 맥락 문구로 수정(예: `로그인 오류`)

### 낮음

1. 인라인 에러 메시지 UI 미사용 코드 존재
- 위치: `.error-message` / `.error-message.show`
- 문제:
  - 기본 `opacity: 0` 상태이나 `.show` 토글 로직 없음
- 영향:
  - 실제로는 표시되지 않는 스타일/DOM가 남아 유지보수 복잡도 증가
- 권장 조치:
  - 인라인 검증을 쓸 계획 없으면 제거
  - 사용할 계획이면 상태 기반 표시 로직 추가

2. 미연결 UI 요소 존재
- 위치: `로그인 상태 유지`, `비밀번호를 잊으셨나요?`
- 문제:
  - 체크박스 상태가 인증 로직과 연결되지 않음
  - 비밀번호 찾기 링크가 placeholder(`#`)
- 영향:
  - 사용자 기대와 실제 동작 불일치
- 권장 조치:
  - 기능 연결 전까지 비활성/숨김 처리 또는 TODO 명시

### 총평

- 로그인 기본 API 흐름은 유지되어 이식 방향은 적절함.
- 우선순위는 소셜 로그인 이벤트 처리(보안/중복 실행 방지) 개선.
